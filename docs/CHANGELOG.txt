2026-09-23  -  02:16 AM - 02:41 AM

Built Lenticular Workbench v1 on the scaffold, per the user's full brief.

Added:
- src/lenticular/core/: units, interlace (N-frame, absolute-position slot
  assignment, optical inversion, phase, nearest/blend boundaries,
  lenticule-average/direct sampling, view simulation), calibration
  (coarse/refine/phase candidates, sheet layout), profiles (separate lens
  and printer stores with CRUD + JSON import/export, calibration session),
  encode (PNG pHYs injection, TIFF), checks, transform.
- src/lenticular/ui/: Calibrate (7 steps incl. band-count helper and
  resolution warning), Create (lens/printer, size presets in in/mm,
  frames with drag reorder, Reverse, loop/ping-pong, built-in test
  frames, alignment editor with ghost/difference overlay, drag/scroll,
  crop/fit/rotate/flip, copy/paste/reset/apply-to-all; generate;
  simulated preview with viewing slider; print-safety checklist gating
  PNG/TIFF export), Lens Profiles, Printer Profiles, Settings.
- src/main.js: mounts the app; registers lwHeader/lwMain with the UI
  Layout Engine (data/processed/ui-layout-config.json); new "Workbench
  Display" dev-panel group (5 controls); settings schema version 1 → 2.
- tests/core.test.mjs (21 tests) + tests/fixtures/interlace-golden.json.
- docs/INTERLACING_METHOD.md (method, evidence labels, references).

Fixed (during the build):
- Element.append(null) printed "null" in the Calibrate derived panel --
  added a null-skipping add() helper.
- The inch ruler length mixed px and mm and overlapped the 50 mm box --
  moved it to its own row with the length computed in print pixels.
- Refine candidates didn't rebuild until a tab switch -- committed
  changes now re-render.

Verified:

- Browser (1400×900 and 375×812): full calibrate → refine (to 100.347) →
